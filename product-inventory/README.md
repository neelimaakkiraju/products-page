# Product Inventory App

This is a React + TypeScript + Vite project for managing product inventory.

## Project File Structure

```
product-inventory/
├── eslint.config.js
├── index.html
├── package.json
├── postcss.config.js
├── README.md
├── tailwind.config.js
├── tsconfig.app.json
├── tsconfig.json
├── tsconfig.node.json
├── vite.config.ts
├── public/
│   └── vite.svg
├── src/
│   ├── App.css
│   ├── App.tsx
│   ├── index.css
│   ├── main.tsx
│   ├── types.ts
│   ├── assets/
│   │   └── react.svg
│   ├── components/
│   │   ├── ProductCard.tsx
│   │   └── ProductFormModal.tsx
│   ├── data/
│   │   └── products.json
│   └── hooks/
│       └── useProducts.ts
```

## Available Commands

Run these commands from the `product-inventory` directory:

| Command           | Description                     |
| ----------------- | ------------------------------- |
| `npm run dev`     | Start development server (Vite) |
| `npm run build`   | Build for production            |
| `npm run lint`    | Run ESLint for code linting     |
| `npm run preview` | Preview production build        |
